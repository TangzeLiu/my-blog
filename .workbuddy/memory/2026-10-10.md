# 2026-10-10 工作日志

## 搭建个人博客网站（BlogWeb）

**需求**：用户想搭建个人博客，最终选型为「从零手写前端 + 技术/学习笔记定位 + 免费托管（GitHub Pages）」。

**方案**：纯 HTML/CSS/JS 手写静态博客，文章用 Markdown 撰写，页面端用 marked.js 实时渲染，highlight.js 做代码高亮。无框架、无打包工具、无第三方运行时依赖。

**已完成的文件**：
- `index.html` 首页（文章列表 + 关键词搜索 + 标签筛选）
- `post.html` 文章页（读取 ?slug= 加载 Markdown 渲染）
- `archive.html` 归档页（按年份汇总）、`about.html` 关于页
- `css/style.css` 全站样式（CSS 变量驱动，含浅色/深色主题、响应式）
- `js/theme.js` 主题切换、`js/main.js` 首页逻辑、`js/post.js` 文章页逻辑
- `posts/` 目录 + 2 篇示例文章 + 自动生成的 `posts.json`
- `scripts/build-index.js` 无依赖 Node 脚本，扫描 md frontmatter 生成索引
- `.nojekyll`（GitHub Pages 跳过 Jekyll）、`.gitignore`、`README.md`

**关键技术点**：
- 文章索引由 `node scripts/build-index.js` 从每篇 md 顶部 frontmatter（title/date/tags/summary）自动生成，避免手动维护。
- 本地预览必须用 http 服务器（有 fetch 跨域限制），不能直接双击打开 html。

**验证**：本地 `python -m http.server 8000` 预览，index/post/style/posts.json 均 200 正常。

**下一步（用户可自行）**：替换站点名/自我介绍/联系方式，推送到 GitHub 并开启 Pages。
