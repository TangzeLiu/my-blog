## 一、准备数据

$$\mathbf{X} = \begin{bmatrix} x_1 \\ x_2 \\ ... \\ x_n \end{bmatrix}\qquad \mathbf{T} = \begin{bmatrix} t_1 \\ t_2 \\ ... \\ t_n \end{bmatrix}$$

<center>
$\mathbf{X}$为年龄，$\mathbf{T}$为身高。
</center>

```python
import numpy as np
import matplotlib.pyplot as plt
import os

X_min = 4
X_max = 30  # 年龄范围在4~30
X_n = 16
X = 5 + 25 * np.random.rand(X_n)
Prm_c = [170, 108, 0.2]
T = Prm_c[0] - Prm_c[1] * np.exp(-Prm_c[2] * X) + 4 * np.random.randn(X_n)

# 数据可视化
plt.figure(figsize = (4, 4))
plt.plot(X, T, marker = 'o', linestyle = 'None', markeredgecolor = 'black', color = 'cornflowerblue')
plt.xlim(X_min, X_max)
base_path = os.path.dirname(__file__)
save_path = os.path.join(base_path, "1.png")
plt.savefig(save_path, dpi=300, bbox_inches="tight")
plt.show()
```

## 二、直线模型

#### 模型：
$$y(x)=w_0x+w_1$$

$\quad$我们需要用一条直线来拟合给定的数据,这样一来就可以根据输入的$x$来确定输出的$y$是多少。不难发现这条直线就是由$w_0$和$w_1$这两个参数决定的，于是问题就转换为如何确定$w_0$和$w_1$这两个参数来找到一条理想的直线。

#### 误差函数：

$\quad$新的问题又出现了，怎样的直线算是理想的呢？我们使用误差函数来评估数据的拟合程度。常用的误差函数为均方误差（Mean Square Error MSE）。
$$J = \frac{1}{N}\sum_{i=1}^n (y_i - t_i)^2$$
$\quad$其中$y_i$表示直线模型中输入为$x_i$时的输出，$t_i$表示实际的输出。从定义中不难得到，我们希望误差函数越小越好。

#### 求参数（梯度下降法）

$\quad$重新整理一下现在要解决的问题，就是找到一组$w_0$和$w_1$，使得误差函数$J$的值最小。我们使用梯度下降法来求解。

$\quad$梯度下降法的直观理解：假设我们站在山上的某一个点，现在要走到山底，我只知道当前这个点朝哪个方向下降最快（最陡），于是就选择这个方向往下走，重复这样的步骤，最终走到山底。那个方向就是$J$的梯度的反方向。

于是我们可以得到学习法则，及参数$\vec w$的更新原则：

$$\vec w(\tau+1) = \vec w(\tau) - \alpha\left.\nabla_wJ\right|_{w(\tau)}$$

$J$的梯度，即$w_0$和$w_1$偏导数向量如下：

$$\nabla_wJ = \begin{bmatrix} \frac{\partial J}{\partial w_0} \\[6pt] \frac{\partial J}{\partial w_0} \end{bmatrix}$$

$$\frac{\partial J}{\partial w_0} = \frac{2}{N}\sum_{i=1}^n(y_i - t_i)x_i$$
$$\frac{\partial J}{\partial w_1} = \frac{2}{N}\sum_{i=1}^ny_i - t_i$$

```python
# 均方误差的梯度
def dmse_line(x, t, w):
    y = w[0] * x + w[1]
    d_w0 = 2 * np.mean((y - t) * x)
    d_w1 = 2 * np.mean(y - t)
    return d_w0, d_w1

# 梯度法求参数
def fit_line_num(x, t):
    w_init = [10.0, 165.0]  # 初始参数
    alpha = 0.001   # 学习率
    tau_max = 100000    # 重复的最大次数
    eps = 0.1   # 停止重复的梯度绝对值的阈值
    w_hist = np.zeros([tau_max, 2])
    w_hist[0, :] = w_init
    for tau in range(1, tau_max):
        dmse = dmse_line(x, t, w_hist[tau - 1])
        w_hist[tau, 0] = w_hist[tau - 1, 0] - alpha * dmse[0]
        w_hist[tau, 1] = w_hist[tau - 1, 1] - alpha * dmse[1]
        if max(np.absolute(dmse)) < eps:
            break
    w0 = w_hist[tau, 0]
    w1 = w_hist[tau, 1]
    w_hist = w_hist[:tau, :]
    return w0, w1, dmse, w_hist
```
